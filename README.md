## What I do

- **Product thinking** — clarify the problem, scope the MVP, and turn ambiguity into an executable plan.
- **Experience design** — shape information architecture, interaction details, and visual hierarchy.
- **Rapid prototyping** — build working interfaces with HTML, CSS, JavaScript, Python, and SwiftUI.
